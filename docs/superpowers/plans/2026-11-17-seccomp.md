# syscall_filter= / seccomp family (audit 4.6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hand-built seccomp for services: systemd's SystemCallFilter= with its named groups, plus SystemCallArchitectures=native, RestrictSUIDSGID, LockPersonality, RestrictRealtime, RestrictNamespaces=yes.

**Architecture:** Generated tables (groups pre-expanded, names → `__NR_` at compile time); a pure `seccomp.c` that builds a classic-BPF program (arch check, sibling arg checks, a balanced BST with BPF_JA trampolines) and installs it; service.c parses into a compact `sc_spec_t`; the child installs it as the last step before execve (main and runner).

**Tech Stack:** C99, linux/seccomp.h, linux/filter.h, linux/audit.h; bash generator over `systemd-analyze syscall-filter`; Python importer.

**Spec:** `docs/superpowers/specs/2026-11-17-seccomp-design.md`

## Global Constraints
- Default action for a blocked call: EPERM (NOT kill); `syscall_error_number=kill` kills; per-entry `:ERRNO` wins.
- First syscall_filter= line sets mode (plain = allow, `~` = deny); later lines add, opposite-sign lines remove; empty clears.
- Allowlist implies native-arch-only. x86_64 refuses the x32 bit.
- execve/execveat always ALLOW.
- Any seccomp key implies no_new_privs unless CAP_SYS_ADMIN is still effective at install.
- BPF ≤ 4096 instructions; jt/jf ≤ 255, farther via BPF_JA.
- Arg checks on the low 32 bits (endian-aware offset).
- Pointer-arg calls: openat2 → ENOSYS (suid), sched_setattr → EPERM (rt), clone3 → ENOSYS (ns).
- SCHED_RESET_ON_FORK masked; O_TMPFILE counts as creating.
- No docstrings; why-comments only.

## Review Focus
1. A large allowlist (`@system-service` ≈ 400) whose BST needs trampolines: still loads and allows/denies correctly at both ends. Test: Task 2 `test_big_allowlist` (min and max syscall numbers in the set, one just outside).
2. i386 compat on x86_64 with an allowlist but no syscall_architectures: refused. Test: Task 2 (x86_64 only) `test_compat_denied` via int 0x80 getpid.
3. Filter installed after the uid drop and landlock: the service's own setup never trips it (a denylist of `@setuid` still lets the service start as user=nobody). Test: Task 4 live.
4. `restrict_namespaces` doesn't break plain fork/pthread_create (clone without CLONE_NEW*). Test: Task 2 sibling cases.
5. An unknown syscall name refuses the load, a name the arch lacks is silently skipped. Test: Task 3.

### Task 2: seccomp.c builder and installer
**Files:** create `seccomp.h`, `seccomp.c`; `tests/test_seccomp.c` + Makefile; add seccomp.c to SRCS/ENGINE_OBJS/link lines and CORE_HDRS.
**Produces:**
```c
#define SC_WORDS ((SC_NAMES_ALL + 63) / 64)
#define SC_KILL 0xFFFF
typedef struct {
    uint8_t  mode;           /* 0 none, 1 allow, 2 deny */
    uint64_t set[SC_WORDS];  /* bit i = sc_known[i] */
    uint16_t err;            /* default errno for blocked calls (0 = EPERM), SC_KILL = kill */
    uint8_t  n_over;
    struct { uint16_t idx; uint16_t err; } over[32];
    uint8_t  native, suid, persona, rt, ns;
} sc_spec_t;
int sc_active(const sc_spec_t *s);
int sc_build(const sc_spec_t *s, struct sock_filter *out, int max);   /* count or -1 (too big) */
int sc_install(const sc_spec_t *s, const char **step);                  /* 0 / -1 */
int sc_add(sc_spec_t *s, const char *entry, int negate);               /* name/@group[:ERRNO]; -1 unknown */
```
- [ ] tests (fork per case, child installs, parent reads exit/signal): allowlist {read write exit_group …minimal + getpid} → getpid ok, getuid EPERM; `syscall_error_number=kill` → SIGSYS; denylist {getuid} → getuid EPERM, getpid ok; per-entry `getuid:EACCES`; `@system-service` allowlist runs `/bin/true` via execve; `test_big_allowlist`; x32 refused (x86_64); compat int 0x80 refused with allowlist (x86_64); suid: chmod 04755 EPERM, 0755 ok, open O_CREAT 04755 EPERM, O_TMPFILE|O_RDWR 02755 EPERM, openat2 ENOSYS, mknod S_IFREG|04755 EPERM; persona: personality(0) ok, personality(0xffffffff) ok, personality(PER_BSD) EPERM; rt: sched_setscheduler FIFO EPERM, FIFO|RESET_ON_FORK EPERM, OTHER ok, sched_setattr EPERM; ns: unshare(CLONE_NEWNS) EPERM, fork ok, clone3 ENOSYS, setns EPERM; sc_build of an absurd spec (every syscall with a distinct errno) stays ≤ 4096 or returns -1.
